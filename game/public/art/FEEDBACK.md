## 给开发 AI 的反馈

1. 首战中仍有大块程序几何布景，与正式插画背景并存，画风和遮挡比较突兀。建议调整这些布景的材质、尺寸与层级，避免遮住远景主体。
2. 多个敌兵与主角靠近时图片重叠明显，建议结合纵深位置排序、敌人分散站位和命中反馈改善辨识度。
3. 当前动作是离散单帧素材。步行已区分两帧，但攻击、受击等仍需结合播放时长与位移调节；不要把静态插画直接当作完整连续动画。
4. 按每帧内容框归一化会受长武器、披风和特效影响。建议接入时检查各角色跨姿势的身体大小与落脚点，需要时引入角色级缩放、姿势偏移元数据。
5. 场景提示词要求可平铺，但本轮未验证所有纹理在重复采样下像素级无缝。建议在五章场景实测横向远景接缝和地面重复效果。
6. 211 张 PNG 总计约 107 MiB。部署后检查首屏与切换角色的加载表现，按需考虑分章加载或额外导出 WebP；保留本次 PNG 作为制作源文件。
7. 本轮按美术分工只交付 `game/public/art/`，另执行用户明确要求的无关 Markdown 清理。根目录 `docs/` 的 GitHub Pages 构建产物没有更新。开发 AI 发布前请运行 `npm run build:pages`，提交新的 `docs/`，再确认线上页面。
8. Boss / 敌兵清单只有 `walk1`；当前 `SpriteRig.poseOf` 会统一交替请求 `walk2`，不存在时回退到 `idle`。建议按资源可用情况选择步行帧，避免把这种回退误认为缺图；本次严格交付清单规定的 211 张。

本地试玩已可进行；以上改进可在试玩反馈后继续开发，不必等待云端 AI 才能启动游戏。
