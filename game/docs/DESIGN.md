# 烬渊 · Ashen Abyss — 设计文档

横版 3D 街机清版动作游戏(beat 'em up),运行于浏览器。暗黑风。

## 1. 参考与定位

| 参考 | 取其什么 |
|---|---|
| 名将 (Captain Commando) | 左右连击、抓投、清版节奏 |
| 三国战记 | 指令技、道具、多角色、分支路线 |
| 战国传承3 (Sengoku 3) | 轻重攻击取消链、空中连段、必杀取消 |
| 英雄联盟 | 3 路地图结构(上/中/下路 + 野区连接) |
| DNF | 房间制关卡、过关动画、评分 |

## 2. 技术栈

- TypeScript + Vite + Three.js,纯前端,零后端,可部署到 GitHub Pages
- 逻辑与渲染分离:`sim/` 是确定性固定步长(60Hz)模拟,不依赖 DOM / Three.js
  - 这样同一份模拟代码可以:① 游戏里跑 ② Web Worker 里无渲染高速跑(AI 训练) ③ Node 里跑单元测试
- 数据驱动:角色、招式、地图全部是 JSON(带 schema 校验),编辑器只是 JSON 的 GUI

## 3. 目录结构

```

      ai/           脚本 AI 与神经网络策略接口

    ui/         HUD、菜单、按键配置、过关动画
    data/       内置角色、招式、地图、故事(JSON / TS)

  tests/        模拟层单元测试 + Playwright 冒烟测试
  docs/
```

## 4. 操作与战斗系统

### 4.1 按键(全部可自定义,存 localStorage)

| 功能 | 默认键 |
|---|---|
| 移动 | W A S D(横向 X 轴 + 纵深 Z 轴) |
| 轻拳 LP / 重拳 HP / 轻脚 LK / 重脚 HK | J / K / U / I |
| 跳跃 | 空格 |
| 技能 1..N(默认 4 个,可增至 8) | 1 2 3 4 … |
| 闪避 | L |

支持手柄(Gamepad API)。

### 4.2 连招规则(战国传承3 风格取消链)

- 取消层级:`轻攻击 → 重攻击 → 指令技 → 技能 → 奥义`,命中或被防时可向更高层级取消
- 同级连打:轻拳可自连最多 3 下(名将式左右连击)
- 指令输入:方向 + 按键,如 `↓→ + LP`、`→→`(冲刺)、`↓↑ + HK`、`LP+LK`(抓投)
- 输入缓冲 8 帧,指令识别窗口 20 帧
- 空中连段:浮空后可追打,每次追打浮空高度递减(重力补正)

### 4.3 连击上限(防无限连)

- 连击计数器:每一击累加「连击值」(轻 1,重 2,技能 3)
- 伤害补正:第 N 击伤害 ×max(0.2, 1 − 0.08·(N−1))
- 连击值达到上限(默认 30)后,对手强制倒地并获得起身无敌
- 同一招式在一套连段内最多使用 2 次(第 3 次强制击飞脱离)

### 4.4 资源

- HP、能量(攻击与受击积累,技能与奥义消耗)、防御槽(破防)

## 5. 地图

- **路线图**(LoL 式 3 路):每章是一张节点图,上/中/下三路,路间有「野区」连接点可换路;
  每路 3~4 个战斗房间,三路汇合于 Boss 房
- **房间**(DNF 式):固定宽度的横版场景,清光敌人后开门,播放过关动画与评分(连击数、受伤、用时)
- 不同路线:敌人构成、奖励、剧情片段不同,鼓励多周目

## 6. 世界观与故事

**烬渊纪元**。三百年前,王国「艾瑟兰」的贤者们为求永恒之火,凿穿了大地,
唤醒了沉睡在地心的「烬渊」——一团会思考的余烬。它不燃烧木石,只燃烧记忆。
被它触碰的人忘记自己是谁,化为「空烬者」,游荡于灰雪之下。

王都陷落之夜,最后一任守火女王将自己的名字劈成十片,封入十件「名之遗物」。
持有遗物者不会被烬渊夺去记忆——但每使用一次力量,就会失去一段属于自己的过往。

十位持名者自三条古道(誓约之路、灰雪之路、深根之路)向王都进发。
他们要在自己被彻底遗忘之前,把女王的名字还给深渊。

### 章节

1. **灰雪边境** — 被遗弃的哨站与空烬者村落。Boss:忘名骑士长 加雷斯
2. **泣骨修道院** — 试图用祷文记住一切的修士们。Boss:千页主教
3. **深根矿道** — 贤者凿穿大地的旧迹。Boss:掘墓巨像
4. **无王之都** — 王都废墟。Boss:守火女王的余影
5. **烬渊之心** — 最终章。Boss:烬渊本体「无名者」

## 8. 浏览器端 AI 训练

- **目标**:敌人与陪练 AI 可在玩家浏览器里自我对战训练,不需要服务器
- **环境**:`sim/` 无渲染模式在 Web Worker 中以数千步/秒运行
- **观测**:自身与最近对手的相对位置、速度、状态、HP、能量、帧优势等 ~40 维向量
- **动作**:离散动作空间(移动 9 向 × 攻击/技能/跳/闪避/无)
- **模型**:小型 MLP(2×64 隐层),纯 TypeScript 实现前向与反向传播
  - 阶段一:CPU(Float32Array)+ 进化策略 / PPO-lite,多 Worker 并行
  - 阶段二:WebGPU 计算着色器批量推理(可用时自动启用,否则回退 CPU)
- **自博弈**:对手池(历史快照)采样,防止策略坍缩
- **持久化**:权重存 IndexedDB,可导出/导入 JSON
- **界面**:训练面板显示代数、胜率曲线、步/秒,可一键让训练出的 AI 上场

## 9. 角色与地图制作系统

- **角色编辑器**:体型与配色、属性、招式列表(帧数据、判定框、取消路线、指令)、实时预览与木桩测试
- **地图编辑器**:路线图节点拖拽、房间布景与敌人波次配置
- **格式**:JSON + 校验器(数值范围、帧数合法性、平衡预算点数,防止超模角色)
- **分享**:导出/导入 JSON 文件;内置内容与用户内容走同一套加载路径
