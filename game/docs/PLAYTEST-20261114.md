## 用户反馈与停止要求

用户连续反馈：

> 现在呢 我看页面是卡着的，而且啊 还不动，你是不是加了什么疯狂消耗cpu 或 gpu的代码呀

> 算了 我把页面关闭了 ，你这样测试 让我很担心啊

> 系统资源都被你抢光了

用户最终要求只把记录提交上传 GitHub，之后停止工作。

页面不动与本次显式开启逐帧暂停相符。但临时实现只暂停模拟时间，仍持续执行 `requestAnimationFrame`、HUD 更新和 Three.js 渲染；因此暂停模拟不会停止渲染负载。这是实现中的明确疏漏。浏览器配置与渲染方式可能影响负载，但此次没有取得高峰期间的进程级 CPU/GPU 证据，不能确定全部资源占用来源。

清理后的两次总 CPU 瞬时采样分别为 22% 和 43%；后一采样可用物理内存约 25,329 MiB，总内存约 65,150 MiB。这些是事后快照，不能代替高峰测量，也不能用来否定用户的卡顿反馈。
