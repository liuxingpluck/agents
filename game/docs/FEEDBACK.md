### 2026-11-15(跳跃 / 跑动时人物有时会隐身)

| 意见 | 做了什么 |
|---|---|
| 跳跃、跑动时人物有时隐身,是不是缺关键帧 | 不是缺图。原因是每个姿势的图**第一次用到时才去下载**,在线上(GitHub Pages)下载要几百毫秒,下载完成前那几帧贴上去的是空图,人物就透明了——跳跃、跑步四帧、空中攻击这些姿势最容易碰到。改成:角色一出场就把他全部姿势图提前下载;万一某张还没下载好,先继续显示上一张图,不再出现透明帧。用模拟 0.4 秒和 1.2 秒网络延迟实测,跳跃 / 跑动 / 空中攻击过程中画不出人物的帧从将近一半降到 0 |
| (同一现象的另一个来源) | 起身、空中受身后的无敌时间,人物原来是整个一闪一闪地消失,也像隐身。改成半透明闪烁 |
| 要不要生成新图 | 这个问题不需要新图,所以没有出新的提示词 |

### 2026-11-13(跑动别扭、K 键不爽、要不要让 Codex 继续出图)

| 意见 | 做了什么 |
|---|---|
| K 键用着很不爽 | 找到三个原因并都改了:① 之前「按住 K 蓄力」会让普通的按 K 也卡一下才出招——现在**点按立刻出招**,只有打完第一下还按着不放才转入蓄力;② 重攻击出手太慢(原来 8~14 帧)——现在按职业 6 / 7 / 9 帧,收招也缩短;③ 重攻击原地不动打不到人——现在每一下都会向前踏一步 |
| 跑动有问题 | ① 以前只能「快速按两下方向」才跑,现在**按住方向走一小会儿(约 0.25 秒)就自动跑起来**,双击仍然立刻跑;② 以前迈步图是按时间切换的,和实际移动速度对不上,看起来脚在滑——现在按走过的距离切换;③ 走 / 跑时身体有起伏和前倾,跑步脚下扬尘 |
| (自己查出来的)出招时角色忽大忽小、前后乱跳 | 第一批图是按「内容撑满画布」缩放的,剑一伸出去整个人就被缩小约 25%。现在构建时会测量每张图,游戏里自动把人物放大回同样的体型并对齐位置。出招时还加了「后仰蓄势 → 前冲 → 收回」的身体动作 |
| (自己查出来的)打击火花是灰色的多边形,像贴图坏了 | 换成发光的星芒火花 |
| 是不是有新图要 Codex 生成 | 是。真正的瓶颈是**每个主角只有 1 张轻击图、1 张重击图、2 张走路图**,所以连招每一下长得一样。第二批清单已备好:`game/art/prompts-v2.json`(262 张,分 4 个优先级),说明在 `game/docs/ART-GUIDE.md` 的「第二批」一节。游戏代码已经留好位置,图放进来自动生效 |

### 2026-11-14(用户在对话里提的一批意见)

| 意见 | 做了什么 |
|---|---|
| 连招互动太单一、不够华丽 | 连招路线加长:轻攻击打满 → 重攻击打满(最后一下挑空)→ 跳起追击 → 空中连打 → 空中重击把对手砸向地面、弹起后还能接。加了一批特效(见最后一行) |
| 没有空中连招 | 空中轻攻击统一可连 3 下;空对空命中时自己会上浮,能在空中多停一会儿;空中重击是「砸地技」,对手落地弹起一次;空中追打的浮空衰减减半;飞行道具类技能可以在空中放 |
| K 键意义不大 | 重攻击现在有三个专属用途:① **按住蓄力**,蓄得越久伤害越高,蓄过半会破防并把人打飞;② 对格挡的消耗是轻攻击的两倍;③ 重攻击连段的最后一下是挑空,是空中连招的起点。另外坦克 / 狂战士的重攻击能连 4 下 |
| 抓取要有范围,各职业不同 | 10 个职业的抓取范围从 1.0 米到 2.9 米不等(刺客要贴身,死灵法师的骸骨之手最远),抓得远的出手更慢。选人界面和招式表里会显示 |
| 不同按键、不同职业的连击数应该不同 | 轻攻击 2~5 下、重攻击 2~4 下,因职业而异(格斗家 / 刺客轻攻击 5 下;坦克 / 狂战士轻 2 下但重 4 下……),表在 `src/data/tuning.ts` |
| 最好有格挡 | **按住 Shift = 格挡**(只挡正面,会消耗防御值,耗尽被破防);刚按下的瞬间挡住 = **弹反**,不掉血且对手陷入硬直。方向 + Shift 仍是闪避。抓投和蓄力重击能破格挡。持盾的敌人(无王卫士、骑士长)也会格挡 |
| 地图没有随机遮挡物、形不成地形防御 | 每个战斗房间随机摆 4~6 个障碍物:岩石、木箱、木桶、路障。挡路也挡飞行道具(可当掩体),矮的能跳过去,木箱 / 木桶 / 路障能打碎。敌人会绕行 |
| 地图不够凹凸不平 | **只做了障碍物,没做真正的高低地形**(高台、斜坡)。原因:高低差会牵涉落地、击飞、敌人寻路等一大串规则,风险较高,想先看你对障碍物的感受再决定要不要做 |
